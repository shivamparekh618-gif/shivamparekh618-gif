## Projects

### [Startup Equity Toolkit](https://github.com/shivamparekh618-gif/startup-equity-toolkit)
Turns one config file into a cap table, a control report, a vesting and 83(b) calendar, buyout math that always adds up to the exact unit, and a members' consent built from the same numbers. Grew out of running LetsNavi's equity restructure. The repo uses a fictional company.
**Result:** shows why a 45% holder controls 57% of the vote (unissued reserve units don't vote), something a spreadsheet with only a "%" column never shows.

### [Restaurant Order Reconciliation](https://github.com/shivamparekh618-gif/restaurant-order-reconciliation) · [live demo](https://shivamparekh618-gif.github.io/restaurant-order-reconciliation/)
Matches delivery-app orders against a restaurant's POS, even when staff type the order ID wrong or leave it blank. It flags orders that never reached the kitchen, cancellations that weren't voided and menu prices that drifted apart, then ranks them by dollars at risk. Shaped by running a restaurant floor and by the problems ServiQ works on.
**Result:** traces 141 small price mismatches to a single stale menu price worth about $6k a year, with 100% match precision against the answer key.

### [NYC 311 Backlog Triage](https://github.com/shivamparekh618-gif/nyc-311-backlog-triage) · [live demo](https://shivamparekh618-gif.github.io/nyc-311-backlog-triage/)
Sorts 311 complaint queues into *growing*, *chronic* and *healthy*, and finds the week a queue started falling behind.
**Result:** pinpoints the week street-light closures fell 41%, and shows why the biggest-looking backlog was the one to leave alone.

## How I work

1. **Start with the decision.** Who is going to act on this, and what would they do differently?
2. **Be honest about the data.** Every cleaning rule gets counted and shown, not applied silently.
3. **Rank, don't just report.** A list of 250 problems is noise; the top 13 with a next step is a to-do list.
4. **Look for the one upstream fix.** One stale price explained 141 exceptions.
5. **One source of truth.** If five documents need the same number, generate all five from one place.
6. **Write down the assumptions and what I'd ask users** before anyone relies on it.
